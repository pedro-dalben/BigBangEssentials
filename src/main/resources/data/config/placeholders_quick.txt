# BigBangEssentials Placeholder Quick Reference
# Condensed list for quick lookup
# For full documentation, see: placeholders.txt

================================================================================
                    QUICK PLACEHOLDER REFERENCE
================================================================================

PLAYER INFO:
  {bigbangessentials_name}              - Player username
  {bigbangessentials_displayname}       - Display name
  {bigbangessentials_uuid}              - Player UUID

PERMISSIONS:
  {bigbangessentials_prefix}            - Player prefix (auto-detects LuckPerms/FTB/Internal)
  {bigbangessentials_suffix}            - Player suffix
  {bigbangessentials_group}             - Player group

LUCKPERMS (requires LuckPerms mod):
  {luckperms_prefix}                - Prefix from LuckPerms
  {luckperms_suffix}                - Suffix from LuckPerms
  {luckperms_group}                 - Primary group from LuckPerms
  {luckperms_displayname}           - Full formatted name

PLAYER STATUS:
  {bigbangessentials_health}            - Current health
  {bigbangessentials_food}              - Food level
  {bigbangessentials_level}             - XP level
  {bigbangessentials_gamemode}          - Game mode

LOCATION:
  {bigbangessentials_world}             - Current world
  {bigbangessentials_x}                 - X coordinate
  {bigbangessentials_y}                 - Y coordinate
  {bigbangessentials_z}                 - Z coordinate
  {bigbangessentials_biome}             - Current biome

ECONOMY:
  {bigbangessentials_balance}           - Balance
  {bigbangessentials_balance_formatted} - Formatted balance

AFK:
  {bigbangessentials_afk}               - AFK indicator
  {bigbangessentials_afk_time}          - Time AFK
  {bigbangessentials_afk_reason}        - AFK reason

SERVER:
  {bigbangessentials_server_name}       - Server name
  {bigbangessentials_online_players}    - Players online
  {bigbangessentials_max_players}       - Max players
  {bigbangessentials_time}              - Current time
  {bigbangessentials_date}              - Current date

================================================================================
                        COMMON EXAMPLES
================================================================================

Simple:
  {bigbangessentials_prefix}{bigbangessentials_name}: {MESSAGE}

With LuckPerms:
  {luckperms_prefix}{bigbangessentials_name}{luckperms_suffix}: {MESSAGE}

With Location:
  {bigbangessentials_prefix}{bigbangessentials_name} [{bigbangessentials_world}]: {MESSAGE}

With AFK:
  {bigbangessentials_prefix}{bigbangessentials_name}{bigbangessentials_afk}: {MESSAGE}
