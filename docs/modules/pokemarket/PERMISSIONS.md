# Permissões do PokéMarket

## Permissões de Uso
- `bigbangessentials.pokemarket.use`: Uso geral do PokéMarket (root gate).
- `bigbangessentials.pokemarket.sell`: Permissão para criar anúncios de venda.
- `bigbangessentials.pokemarket.trade`: Permissão para criar anúncios de troca.

## Limites de Anúncios Ativos
- `bigbangessentials.pokemarket.limit.<N>` (ex: `bigbangessentials.pokemarket.limit.10`, `bigbangessentials.pokemarket.limit.20` ou alias curto `pokemarket.limit.10`): Define o número máximo de anúncios ativos simultâneos do jogador.
- `bigbangessentials.pokemarket.limit.unlimited` (ou `pokemarket.limit.unlimited`): Remove o limite de anúncios ativos.

## Administração
- `bigbangessentials.pokemarket.admin`: Acesso administrativo completo.
